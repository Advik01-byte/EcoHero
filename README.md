# EcoHero: Save the Earth

**Science Holiday Homework Project for Grade 6 ICSE**

EcoHero: Save the Earth is a Java-based educational game made for a Grade 6 ICSE science holiday homework project. In this project, the player becomes an environmental hero and learns how to protect the Earth through fun and interactive activities.

The game is designed to make science learning simple, interesting, and engaging.

## Project Aim

The aim of this project is to teach students about pollution, recycling, and energy saving in a game-like format.

## Main Idea

The user starts from the main menu and moves through different sections of the game. Each section helps the player learn something important about protecting the environment.

## Features

- Main menu
- Learn about pollution
- Recycling game
- Energy-saving challenge
- Final quiz
- Score system

## Java Concepts Used

- Multiple panels using `CardLayout`
- Buttons for navigation and actions
- Images for a better look
- Progress bar to show progress
- Score tracking to count points

## How to Run the App

If you want to run this project on your computer, follow these steps:

1. Install Java JDK on your computer.
2. Open the project in an IDE such as IntelliJ IDEA, Eclipse, or VS Code.
3. Make sure the Java files are inside `src/ecohero`.
4. Run the `ecohero.Main` class.

### If You Are Using the Command Line

1. Open the project folder in terminal or Command Prompt.
2. Compile the Java files:

```bash
javac -d out src/ecohero/*.java
```

3. Run the main class:

```bash
java -cp out ecohero.Main
```

The app does not need any external image files because the pictures are created inside the Java program.

## Project Files

- `src/ecohero/Main.java` - Starts the app
- `src/ecohero/EcoHeroFrame.java` - Main window and panel manager
- `src/ecohero/GameState.java` - Stores score and progress
- `src/ecohero/MainMenuPanel.java` - Main menu screen
- `src/ecohero/PollutionPanel.java` - Pollution learning screen
- `src/ecohero/RecyclingPanel.java` - Recycling game screen
- `src/ecohero/EnergyChallengePanel.java` - Energy-saving challenge
- `src/ecohero/QuizPanel.java` - Final quiz screen
- `src/ecohero/ResultPanel.java` - Final score screen
- `src/ecohero/ImageFactory.java` - Creates the pictures used in the app
